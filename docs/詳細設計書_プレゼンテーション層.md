# Daily Journal — 詳細設計書：プレゼンテーション層

> 最終更新: 2026-05-21

---

## 1. 概要

プレゼンテーション層は `index.html` の HTML 構造と CSS で構成される。  
外部CSSファイル・UIライブラリは使用せず、`<style>` タグにすべて記述する。

---

## 2. カラーパレット（CSS Variables）

`:root` に定義されたカスタムプロパティで全色を一元管理する。

| 変数名 | 値 | 用途 |
|--------|----|------|
| `--bg` | `#f7f6f3` | ページ背景・入力フィールド背景 |
| `--surface` | `#ffffff` | カード・パネルの背景 |
| `--border` | `#e4e2dc` | ボーダー・削除ボタンの初期色 |
| `--text` | `#1c1c1c` | メインテキスト |
| `--text-sub` | `#888` | サブテキスト・ラベル |
| `--accent` | `#5b7fa6` | 日別グループのアクセント色（青） |
| `--accent-light` | `#eef2f8` | アクセントの薄い背景 |
| `--accent2` | `#6a9e7f` | 蓄積グループのアクセント色（緑） |
| `--accent2-light` | `#eef5f1` | accent2 の薄い背景 |
| `--done` | `#aaa` | 完了済みテキストの色 |
| `--danger` | `#c0392b` | 削除ボタンのホバー色 |
| `--radius` | `10px` | カードの角丸 |
| `--shadow` | `0 1px 4px rgba(0,0,0,0.07)` | カードのドロップシャドウ |

## 4. コンポーネント詳細

### 4.1 ヘッダー（`<header>`）

```
.header-row
  h1 "DAILY JOURNAL" — 上部固定タイトル
  .header-actions — 右寄せのアクションボタン群
    .icon-btn — 共通ボタンスタイル（surface背景・border・hover時accent-light）
    .icon-btn.active — アクティブ状態（accent背景・白文字）

.date-nav
  前日・翌日ボタン（‹ ›）
  #date-display — 中央に「YYYY年M月D日（曜日）」
  今日ボタン — accent 背景の強調ボタン
```

### 4.2 タブグループ

2行に分かれたタブ UI。

```
.tab-group
  .group-label.persist / .daily — 「蓄積」「日別」の識別ラベル
  .tab-btn — 各セクションのタブ
    .active-persist — 蓄積グループのアクティブ状態（accent2 緑）
    .active-daily   — 日別グループのアクティブ状態（accent 青）
```

| クラス | 説明 |
|--------|------|
| `.tab-btn` | 非アクティブ状態（白背景・グレーテキスト） |
| `.tab-btn.active-persist` | 緑背景・白テキスト |
| `.tab-btn.active-daily` | 青背景・白テキスト |

### 4.3 パネル（`.panel`）

各セクションのコンテンツ領域。

```
.panel  (display:none がデフォルト)
.panel.active  (display:flex に切り替え)
│
├── .panel-title.persist / .daily — セクションタイトル（色分け）
├── .item-list — アイテムリスト
│   └── .item-row (×N)  ← renderList() で動的生成
└── .add-row — アイテム追加フォーム
    ├── <input type="text">
    └── .add-btn
```

### 4.4 アイテム行（`.item-row`）

セクションによって構成が変わる。`data-key` と `data-index` 属性で編集対象を特定する。

| セクション | チェックボックス | テキスト | 登録日 | ✏️ | × |
|-----------|:--------------:|:-------:|:-----:|:--:|:-:|
| やりたいこと | ✅（緑） | done で打消線 | ✅ | ✅ | ✅ |
| ほしいもの | — | — | ✅ | ✅ | ✅ |
| 目標 | — | — | ✅ | ✅ | ✅ |
| 今日のToDo | ✅（青） | done で打消線 | — | ✅ | ✅ |
| 今日やったこと | — | — | — | ✅ | ✅ |

**インライン編集時の変化：**

```
通常状態:
  [checkbox] [.item-text] [.item-date] [.edit-btn ✏️] [.del-btn ×]

編集状態（startEdit後）:
  [checkbox] [.edit-input（入力中）] [.confirm-btn ✓] [.cancel-edit-btn ✗]
```

### 4.5 カレンダーウィジェット（左サイドバー）

```
#calendar-widget  (width:148px, position:sticky, top:16px)
  .calendar-header
    ◀ ボタン — 前月
    #cal-month — 「YYYY年M月」表示
    ▶ ボタン — 次月
  #calendar-grid  (CSS Grid, 7列)
    .cal-day-header (×7) — 日〜土
    .cal-date (×N) — 各日付セル
      .other-month — 前後月の日付（薄く表示）
      .has-data — 日別データが存在する日（● マーカー）
      .today — 今日（accent 背景・白文字）
      .selected — 選択中の日付
```

### 4.6 一覧ビュー（`#history-view`）

```
#history-view  (display:none → .active で display:flex)
  #history-calendar-widget — 月選択カレンダー
  #history-content
    .history-card (×N) — 各日付のカード
      .history-card-header (クリックで折りたたみ)
        .history-date — 日付
        .history-summary — 「ToDo 2/3　やったこと 3件」
        .history-chevron ▼ (折りたたみ時は ▷)
      .history-card-body
        .history-section-title — 「📋 今日のToDo」など
        .history-items
          .history-item — 各アイテム
            .hi-icon — ✅ / ○ / •
            .hi-text
        .history-journal
          .truncated — 4行に切り捨て（-webkit-line-clamp: 4）
        .expand-btn — 「もっと見る」/「閉じる」トグル
```

### 4.7 トースト（`#toast`）

画面下部中央に3秒間表示されるフィードバック。

```
#toast
  通常: 黒背景・白テキスト
  #toast.error: 赤背景（--danger）
  #toast.show: opacity:1 でスライドイン
```

## 6. アニメーション

| クラス/要素 | アニメーション | 内容 |
|------------|--------------|------|
| `.item-row` 追加時 | `fadeIn` (0.15s ease) | 上から0.25remスライドしながらフェードイン |
| `#toast.show` | transition (0.25s) | 下からスライドアップ＋フェードイン |
| `.history-chevron` 折りたたみ | transition (0.2s) | ▼ → ▷ の回転 |
