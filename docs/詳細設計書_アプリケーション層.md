# Daily Journal — 詳細設計書：アプリケーション層

> 最終更新: 2026-05-21

---

## 1. 概要

アプリケーション層はすべて `<script>` タグ内の Vanilla JavaScript で実装される。  
フレームワーク・ライブラリは使用しない。

---

## 2. 定数

| 定数 | 値 | 用途 |
|------|----|------|
| `STORAGE_KEY` | `'daily-journal-v2'` | メインデータの localStorage キー |
| `SETTINGS_KEY` | `'daily-journal-settings'` | 設定データの localStorage キー |
| `PERSIST_KEYS` | `['wantToDo', 'wishlist', 'goals']` | 蓄積セクションのキー一覧 |
| `DAILY_KEYS` | `['todos', 'didToday', 'journal']` | 日別セクションのキー一覧 |
| `NOTIFY_KEYS` | `{ wantToDo: true, todos: true }` | Discord個別通知の対象セクション |
| `SECTION_LABELS` | `{ wantToDo: {...}, todos: {...} }` | Discord通知のラベル・絵文字・色 |

---

## 3. 状態（State）

| 変数 | 型 | 初期値 | 用途 |
|------|----|----|------|
| `currentDate` | `string` | 今日の日付 | 表示中の日付（YYYY-MM-DD） |
| `activeTab` | `string` | `'wantToDo'` | アクティブなタブのキー |
| `saveTimer` | `number\|null` | `null` | ジャーナル自動保存のタイマーID |
| `historyMode` | `boolean` | `false` | 一覧ビュー表示中かどうか |
| `calendarYear` | `number` | 現在年 | メインカレンダーの表示年 |
| `calendarMonth` | `number` | 現在月(0-11) | メインカレンダーの表示月 |
| `historyCalendarYear` | `number` | 現在年 | 一覧ビューカレンダーの表示年 |
| `historyCalendarMonth` | `number` | 現在月(0-11) | 一覧ビューカレンダーの表示月 |

## 4. 関数一覧

### 4.1 ユーティリティ

| 関数 | 引数 | 戻り値 | 処理 |
|------|------|--------|------|
| `todayStr()` | — | `string` | 今日の日付を `YYYY-MM-DD` で返す |
| `pad(n)` | `number` | `string` | 1桁の数字を2桁の0埋め文字列にする |
| `shiftDate(str, days)` | `string, number` | `string` | 日付文字列を指定日数だけずらして返す |
| `formatDisplay(str)` | `string` | `string` | `YYYY-MM-DD` → `YYYY年M月D日（曜日）` に変換 |
| `esc(str)` | `string` | `string` | HTMLエスケープ（XSS対策） |

### 4.2 レンダリング

| 関数 | 処理 |
|------|------|
| `render()` | 日付表示・全セクションリスト・カレンダーを再描画 |
| `renderList(key, items, isTodo)` | 指定セクションのアイテムリストをDOMに書き出す |
| `renderHistory()` | 一覧ビューの日付カード群を生成してDOMに挿入 |
| `renderCalendar(year, month, gridId, monthId)` | 指定年月のカレンダーグリッドを生成 |

#### `renderList` の描画分岐

```
renderList(key, items, isTodo)
│
├─ items が空 → 「まだ何もありません」表示
│
├─ key === 'wantToDo'
│   → チェックボックス（緑）＋テキスト＋登録日＋✏️＋×
│
├─ isTodo === true（todos）
│   → チェックボックス（青）＋テキスト＋✏️＋×
│
├─ isPersist && addedAt あり（wishlist / goals）
│   → テキスト＋登録日＋✏️＋×
│
└─ その他（didToday など）
    → テキスト＋✏️＋×
```

### 4.3 アクション（データ操作）

| 関数 | 処理 |
|------|------|
| `addItem(key)` | 入力欄の値を取得し、対応するストアに追加。Discord通知も発火 |
| `deleteItem(key, index)` | 指定インデックスのアイテムを削除 |
| `toggleTodo(index)` | 今日のToDo の完了フラグをトグル |
| `toggleWantToDo(index)` | やりたいことの実行済みフラグをトグル（旧フォーマットは自動アップグレード） |
| `startEdit(key, index)` | 指定アイテムをインライン編集モードに切り替え |
| `saveEdit(key, index, newVal)` | 編集内容を保存してリレンダー |
| `cancelEdit()` | 編集をキャンセルしてリレンダー |

#### `addItem` のフロー

```
addItem(key)
│
├─ 入力値が空 → 何もしない
│
├─ key が PERSIST_KEYS に含まれる
│   ├─ key === 'wantToDo' → { text, addedAt, done:false } を push
│   └─ その他 → { text, addedAt } を push
│   → savePersistent()
│
├─ key === 'todos'
│   → { text, done:false } を push → saveDay()
│
└─ その他（didToday）
    → string を push → saveDay()
│
├─ render()
└─ NOTIFY_KEYS[key] が true → notify(key, val)
```

### 4.4 ビュー切り替え

| 関数 | 処理 |
|------|------|
| `setHistoryMode(on)` | メインビュー ↔ 一覧ビューを切り替え。日付ナビの表示も制御 |
| `setCurrentDateFromCalendar(dateStr)` | カレンダーの日付クリック時に `currentDate` を更新して再描画 |

#### `setHistoryMode` の制御対象

| 要素 | historyMode=true | historyMode=false |
|------|-----------------|------------------|
| `#main-view` | `display: none` | `display: contents` |
| `#history-view` | `.active` クラス追加 | `.active` クラス削除 |
| `#date-nav` | `visibility: hidden` | `visibility: ''` |
| `#history-toggle` | `.active` クラス追加（ボタン強調） | `.active` クラス削除 |

### 4.5 Discord 通知

| 関数 | 処理 |
|------|------|
| `notify(key, text)` | 個別アイテム追加時の通知。Webhook URL未設定時はスキップ |
| `sendDailySummary()` | 日次まとめ送信。ToDo・やったこと・ジャーナルを Discord embed で送信 |
| `testWebhook()` | テスト送信。成功/失敗をトーストで通知 |

#### Discord embed フォーマット（日次まとめ）

```json
{
  "embeds": [{
    "title": "📅 日次まとめ — 2026年5月21日（木）",
    "color": 5734566,
    "fields": [
      { "name": "📋 今日のToDo　2/3 完了", "value": "✅ ~~買い物~~\n○ 読書" },
      { "name": "✨ 今日やったこと", "value": "• ジム\n• コーディング" },
      { "name": "📖 ジャーナリング", "value": "今日は..." }
    ],
    "footer": { "text": "Daily Journal" },
    "timestamp": "2026-05-21T..."
  }]
}
```

### 4.6 インライン編集（`startEdit`）

DOM を直接操作してアイテム行を編集モードに変換する。

```
startEdit(key, index)
│
├─ 対象 .item-row を data 属性で特定
├─ .item-text を <input class="edit-input"> に置き換え
├─ .edit-btn を非表示、.del-btn を非表示
├─ ✓ ボタン（confirm-btn）を追加 → saveEdit() 呼び出し
├─ ✗ ボタン（cancel-edit-btn）を追加 → cancelEdit() 呼び出し
└─ Enter → saveEdit()、Esc → cancelEdit()
```

### 4.7 カレンダー

- 7列グリッド（日〜土）で月間カレンダーを生成
- 前月・次月のはみ出し日は薄く表示（`.other-month`）
- 今日は青ハイライト（`.today`）
- 日別データが存在する日には `●` マーカー（`.has-data`）
- 日付クリックで `setCurrentDateFromCalendar()` を呼び出し

### 4.8 設定

| 関数 | 処理 |
|------|------|
| `loadSettings()` | `localStorage` から設定を読み込む |
| `saveSettings()` | 入力欄の値を `localStorage` に保存、トースト表示 |
| `initSettings()` | 起動時に保存済みの Webhook URL を入力欄に復元 |

### 4.9 フィードバック

| 関数 | 引数 | 処理 |
|------|------|------|
| `showToast(msg, isError)` | `string, boolean` | 画面下部にトーストを3秒表示。`isError=true` で赤色 |

## 5. 初期化フロー

```
ページ読み込み
│
├─ migrateV1()          ← v1フォーマットのデータを v2 に変換
├─ migrateV2ToV2_1()    ← 蓄積アイテムを文字列→オブジェクトに変換
├─ initSettings()       ← Webhook URL を入力欄に復元
└─ render()             ← 全UIを初期描画
```

## 6. イベントハンドラー一覧

| トリガー | 処理 |
|---------|------|
| `#history-toggle` click | `setHistoryMode()` トグル |
| `#summary-btn` click | `sendDailySummary()` |
| `#settings-toggle` click | 設定パネルの open クラストグル |
| `.tab-btn` click | タブ切り替え・パネル表示切り替え |
| `#prev-btn` click | `currentDate` を1日前に移動して `render()` |
| `#next-btn` click | `currentDate` を1日後に移動して `render()` |
| `#today-btn` click | `currentDate` を今日にリセットして `render()` |
| `#cal-prev/next` click | `calendarMonth` を前後に移動して `renderCalendar()` |
| `#hist-cal-prev/next` click | 一覧ビューカレンダーの月を前後移動 |
| 各入力欄 keydown(Enter) | `addItem(key)` |
| `#journal-text` input | 600ms デバウンスで `saveDay()` |
