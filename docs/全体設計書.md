# Daily Journal — 全体設計書

> 最終更新: 2026-05-21

---

## 1. プロジェクト概要

| 項目 | 内容 |
|------|------|
| プロジェクト名 | Daily Journal |
| 目的 | やりたいこと・ほしいもの・ToDo・目標・ジャーナルを毎日気軽に記録する個人用Webアプリ |
| 動作環境 | モダンブラウザ（Chrome / Edge / Safari / Firefox） |
| 配布形式 | シングル HTML ファイル（`index.html`） |
| サーバー | 不要（完全ローカル動作） |
| データ保存先 | ブラウザの `localStorage` |

---

## 2. 技術スタック

| 分類 | 技術 |
|------|------|
| マークアップ | HTML5 |
| スタイル | CSS3（CSS Variables / Flexbox / Grid） |
| ロジック | Vanilla JavaScript（ES2020+） |
| ストレージ | Web Storage API（`localStorage`） |
| 外部連携 | Discord Webhook API（任意） |
| 依存ライブラリ | なし |

## 5. セクション一覧

| セクション | 種別 | データ型 | Discord通知 | 実行フラグ |
|-----------|------|---------|------------|----------|
| やりたいこと | 蓄積 | `{text, addedAt, done}[]` | ✅ 追加時 | ✅ あり |
| ほしいもの | 蓄積 | `{text, addedAt}[]` | ✗ | ✗ |
| 目標 | 蓄積 | `{text, addedAt}[]` | ✗ | ✗ |
| 今日のToDo | 日別 | `{text, done}[]` | ✅ 追加時 | ✅ あり |
| 今日やったこと | 日別 | `string[]` | ✗ | ✗ |
| ジャーナリング | 日別 | `string` | ✗ | ✗ |

**蓄積**：日付に関係なく全日共通のデータ  
**日別**：閲覧中の日付に紐づくデータ

## 6. 主要機能一覧

| 機能 | 概要 |
|------|------|
| アイテム追加 | テキスト入力 → 追加ボタン or Enter キー |
| アイテム編集 | ✏️ ボタンでインライン編集（Enter で保存、Esc でキャンセル） |
| アイテム削除 | × ボタン |
| 完了フラグ | やりたいこと・今日のToDoにチェックボックス |
| 日付ナビゲーション | ‹ › ボタンで前後日、「今日」ボタンで当日に戻る |
| カレンダー | 左サイドバーで月間カレンダー表示。記録のある日に●マーク |
| 一覧ビュー | 日別データを日付カード形式で新しい順に表示 |
| ジャーナル自動保存 | 入力から600ms後に自動保存（保存済み✓表示） |
| Discord通知（個別） | やりたいこと・今日のToDo 追加時にリアルタイム送信 |
| Discord通知（まとめ） | 📨 ボタンでその日のToDo・やったこと・ジャーナルをまとめて送信 |
| データ移行 | v1→v2→v2.1 の自動マイグレーション |

---

## 7. 外部連携：Discord Webhook

- **方式**: Discord Incoming Webhook（REST POST）
- **設定場所**: ⚙️ 設定パネル内の Webhook URL 入力欄
- **保存先**: `localStorage`（キー: `daily-journal-settings`）
- **通知トリガー**:
  - やりたいこと・今日のToDoへのアイテム追加（リアルタイム）
  - 📨 まとめボタン（手動、その日のToDo＋やったこと＋ジャーナル）
- **制約**: Discord の field value は最大1024文字（超過時は自動省略）
